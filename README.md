## Problems I've solved

My best work is fixing the chronic problems teams had given up on.

- **Maps rescue (React Native, agribusiness):** the team had given up on the app's maps. I built a replacement for `react-native-maps` as a POC on my own time, and it saved a R$1M contract.
- **5-year-old stock bug (pharmacy system):** stock balances had been wrong for 5 years. I traced it to the front-end deducting from the displayed value without re-querying the server.
- **DynamicForms (digital certificates):** every app rebuilt its own product forms. I created one shared form component with field rules managed centrally, so a rule change reaches every app at once.
- **CI/CD and security (current role):** restructured the pipeline with GitHub Actions, AWS S3 + CloudFront, OIDC and IAM, and implemented a Content Security Policy.
